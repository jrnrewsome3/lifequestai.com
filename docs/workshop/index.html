For facilitators

How to Run This Workshop

This curriculum works in a library meeting room, a senior center, a faith community, or even around a kitchen table. You don't need to be a tech expert — the lessons guide you through everything.

1

Print the handouts

Download and print the one-page reference card for each lesson. Give one to each participant before you begin.

2

Read the lesson aloud or display it

Project the lesson page on a screen, or simply read through each section together as a group.

3

Pause for questions

The safety callouts are great discussion starters. Encourage participants to share experiences.

💡

Workshop Tips

  • Keep sessions to 20–30 minutes each
  • Allow extra time for questions — they're a sign people are engaged
  • Encourage participants not to share personal info during demos
  • Use a laptop or tablet to demonstrate live when possible
  • Remind everyone: it's okay to go slowly
✅

No tech experience needed

This curriculum is designed so any caring person with basic computer access can facilitate it confidently.
